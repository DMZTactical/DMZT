Pasiruošimas

Suplanuok Array apsilankymą ir kuprinėje palik vietos įrašams.

Žingsnis po žingsnio

  1. Pasiek Cheonwang Peak Array ir prieš ieškodamas TV pastato patikrink vietos tikslą.
  2. Array esančiame DBN TV pastate rask antro aukšto Communications Broadcast System ir užbaik jos įsilaužimo veiksmą.
  3. Po įsilaužimo tarp su sistema susijusio grobio rask Encrypted Voice Logs ir paimk nurodytą daiktą.

Atkreipk dėmesį

DBN TV pastatas Cheonwang Peak Array nėra DBN Headquarters vietovėje The Grid. Sek šios užduoties nurodytą pastatą.
