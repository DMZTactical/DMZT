No Time

Page 23

Complete four Dynamic Ops during the same deployment. Unlike the earlier No Time order, this condition is about keeping all four in one run.

Objectives

  • 4×In One Deployment: Complete 4 Dynamic Ops

Objectives in game are authoritative.

Preparation

Plan transport, ammunition and several operation opportunities before starting the chain.

Step by step

  1. Complete four qualifying Dynamic Ops before that deployment ends. Track the current attempt’s completions, not the all-time number in your notes.

Watch out

If the run ends short of four, start a fresh count for the next attempt. Do not combine separate deployments or apply the other No Time’s eight-minute rule.
