Install

  1. Download DMZTactical-Installer.exe.
  2. Run the file. If Windows SmartScreen appears, choose More info and then Run anyway.
  3. Open DMZ Tactical from the Start menu.
  4. If the map does not load, install Microsoft Edge WebView2 and start the app again.

Install WebView2

Update

Open Settings and choose Check for updates. If no update appears, download the installer above and run it. Your plans and settings stay.
